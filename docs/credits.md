# Credits and licenses

This project stands on other people's work:

- **[colorgarden/umi-mainline](https://github.com/colorgarden/umi-mainline):**
  the mainline Linux bring-up for the Mi 10: device tree, panel, touch,
  charger and fuel gauge drivers, and the Adreno firmware.
- **[Nura port](https://github.com/miercolesvd/mi10-port)** (formerly
  postmarketOS): the packaged kernel patch series, sound, modem and boot
  fixes this build reuses.
- **[Arch Linux ARM](https://archlinuxarm.org):** the base system and almost
  every package.
- **[msm-firmware-loader](https://gitlab.nura.eco/postmarketOS/msm-firmware-loader)**
  from postmarketOS/Nura, and **qrtr** and **tqftpserv** from
  [linux-msm](https://github.com/linux-msm).
